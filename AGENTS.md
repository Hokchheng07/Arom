# AROM — Project Instructions & Guidelines

## 1. Project Overview
- **Product:** AROM (អារម្មណ៍) — A bilingual (English & Khmer) mental health and emotional wellness web platform.
- **Core Features:** Emotion/wellness detection, Mindguide, practice exercises, learning modules, community, and professional booking.

## 2. Tech Stack & Libraries
- **Framework:** Next.js 16 (App Router, React 19)
- **Styling:** Tailwind CSS v4 (`@tailwindcss/postcss`) + CSS custom utilities
- **Animations:** Motion (`motion/react` / `motion`)
- **Icons:** `lucide-react`
- **Forms & Validation:** `react-hook-form` + `zod`
- **Typography:** Inter (Latin) & Kantumruy Pro (Khmer)

## 3. Essential Commands
- `npm run dev`: Start local development server (port 3000)
- `npm run build`: Production build check
- `npm run lint`: Run ESLint checks

## 4. Coding & Architecture Standards
- **Component Placement:**
  - Route pages reside inside `app/<feature>/page.tsx`.
  - Shared global components & providers reside in `app/_components/` (e.g., `language-provider.tsx`, `detection-provider.tsx`).
  - Route-specific components are grouped within feature subdirectories.
- **Bilingual & Localization:** Always support or consider English and Khmer text rendering with proper font classes (`font-sans`, Kantumruy Pro).
- **TypeScript:** Strict typing — avoid `any`. Use descriptive interfaces and prop types.
- **Styling Rules:** Ensure mobile responsiveness and accessible contrast suitable for a calming wellness aesthetic.
